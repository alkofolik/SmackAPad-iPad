# 57 — App icon from the existing Smack-a-Pad logo

Status: ready-for-agent. Source: Jakub, 2026-11-03. Part 1 of ticket 46, split off so the icon can ship before the launch animation.
Agent: Gemini 3.8 Flash, high thinking.

## Why

`SmackAPad/Assets.xcassets/AppIcon.appiconset` has an empty 1024×1024 slot, so the app has no icon on the iPad home screen.

## Source

`docs/design/2026-11-03-logo-source/smack-a-pad-icon.svg` (Jakub's existing logo), viewBox 100×100:

- background `#F2F0EA` (cream), drawn as a rect with `rx="22.5"`
- three black pads `#111111`, each 32×32 with corner radius 3, at (14,18), (14,58), (54,58)
- one orange pad `#FF5B1F`, 32×32, radius 3, at (57,11), rotated 12° about (73,27)

Use these colours exactly. Do not recolour to `Theme.orange`.

## Rules

1. **Full-bleed square.** The background fills the whole 1024×1024 canvas with no rounded corners. iPadOS applies the corner mask itself. Pad positions and sizes scale ×10.24 from the SVG.
2. **Opaque PNG, no alpha channel, sRGB.** The App Store rejects an icon with an alpha channel.
3. **How to render.** Do not rely on SVG converters that may not be installed. Write a small Swift script, `docs/design/2026-11-03-logo-source/render-app-icon.swift`, that draws the shapes above with CoreGraphics into an sRGB bitmap context *without alpha* (`CGImageAlphaInfo.noneSkipLast`) and writes `app-icon-1024.png`. Run it with `swift`. Verify the result with `sips -g pixelWidth -g pixelHeight -g hasAlpha`: the output must read 1024 × 1024 and `hasAlpha: no`.
4. Save next to the logo source:
   - `docs/design/2026-11-03-logo-source/app-icon-1024.png`
   - `docs/design/2026-11-03-logo-source/app-icon-square.svg` (the source SVG with the background corner radius removed)
5. Copy the PNG into `SmackAPad/Assets.xcassets/AppIcon.appiconset/` and add its `filename` to the existing single universal entry in `Contents.json`. Keep the single-size setup.
