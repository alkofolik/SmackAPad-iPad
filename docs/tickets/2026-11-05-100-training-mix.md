# 100 — Training: Mix of learned lessons

Status: ready-for-human. Depends on: 98 (Training screen). Source: Jakub, 2026-11-05; legacy "Trénink" concept 2026-10-06 §5 and §6.4 (alternating pieces beats long repetition of one piece for next-day retention).

## Goal

A card **Mix** on the Training screen: 3 learned lessons played one after another, one run each, round and round, until the player stops. Switching between patterns is what makes them stick.

## Choosing the lessons

1. Candidates: lessons with star 2, playable in the current pad mode (8 / 16), open in the player's edition.
2. Pick 3 (2 if only 2 candidates; card disabled with "Mix needs two lessons with two stars." / "Mix potřebuje dvě lekce se dvěma hvězdami." below that): level within ±1 of each other, different categories where possible, prefer lessons played longest ago. Never the same lesson twice in a row.
3. The set is fixed for the calendar day (same Mix when reopened today); a "New mix" / "Jiný mix" button draws another set.
4. The card lists the three titles and a START button.

## Playing

1. Practice screen in a Mix mode: the title area shows "Mix · 2 of 3 · <lesson title>" / "Mix · 2 ze 3 · <název>".
2. Each lesson plays one normal scored run (the ticket 59 run length) at its own **goal tempo**, with its own pattern, pad layout and sound kit. No automatic tempo change in Mix.
3. Between lessons: playback stops, the next lesson loads, and a one-bar count-in at the next lesson's tempo starts it automatically. Seamless switching is not required.
4. A **From memory** toggle on the Mix card (default off) applies to all three; ticket 99 fading applies per lesson (each lesson's first appearance is its pass 1).
5. Each run is recorded to its lesson exactly like a normal full run: stars, Learning credit, reviews (a due lesson's From memory run counts as its review). Challenge mode streaks are per lesson as today.
6. STOP ends the Mix; the result card shows one line per lesson (score, bar verdicts summary) and "Again" / "Znovu".
7. Section loop, Listen and the tempo control are unavailable during Mix.

## Implementation hand-off — 2026-11-05

- Daily selection is a pure function in `TrainingMix.swift`: two-star, edition/stage and pad-mode eligibility; unique lesson IDs; a maximum one-level span; category variety; oldest-played preference; stable day-based ordering. The Training screen persists the selected IDs for each day and pad mode, including a manually redrawn mix.
- `LessonProgress.lastPlayedDay` is optional for old files and updated by the shared full-run recording path. Unknown dates sort before known dates; merging keeps the most recent known date.
- Mix uses one `PracticeSession` and one prepared `AudioEngine`. The scheduler does not enqueue another pass of the old lesson. Once that run's scoring window closes, it executes the normal star, Learning credit and review recording path, flushes that lesson, and swaps the lesson, MIDI pad mapping and resolved sound kit. It never stops or prepares the engine between lessons.
- The next run is anchored to fresh native host time **after** progress, layout and kit work, with 0.6 seconds of scheduling lead followed by four clicks at the next goal tempo. The scorer and pattern display share that same start timestamp. Practice preparation is keyed to session identity, so changing the active lesson does not prepare/restart audio.
- Challenge streaks and appearance counts are retained per lesson. Returning to a lesson continues its memory-hint phase; each newly encountered lesson starts at pass 1. Mix disables Listen, section loops, manual/MIDI tempo changes and automatic tempo progression. Stop shows each selected lesson's latest completed score; Again restarts the set.
- Bar-result counts consume the existing `receiveBarSummary` adapter. The app does not yet produce those verdicts (the adapter explicitly reserves that for a separate scoring ticket), so missing verdicts are displayed as not measured. No new bar-scoring thresholds are invented here.
