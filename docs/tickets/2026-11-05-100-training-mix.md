# 100 — Training: Mix of learned lessons

Status: ready-for-agent. Blocked by: 98 (Training screen). Source: Jakub, 2026-11-05; legacy "Trénink" concept 2026-10-06 §5 and §6.4 (alternating pieces beats long repetition of one piece for next-day retention).

## Goal

A card **Mix** on the Training screen: 3 learned lessons played one after another, one run each, round and round, until the player stops. Switching between patterns is what makes them stick.

## Choosing the lessons

1. Candidates: lessons with star 2, playable in the current pad mode (8 / 16), open in the player's edition.
2. Pick 3 (2 if only 2 candidates; card disabled with "Mix needs two lessons with two stars." / "Mix potřebuje dvě lekce se dvěma hvězdami." below that): level within ±1 of each other, different categories where possible, prefer lessons played longest ago. Never the same lesson twice in a row.
3. The set is fixed for the calendar day (same Mix when reopened today); a "New mix" / "Jiný mix" button draws another set.
4. The card lists the three titles and a START button.

## Playing

1. Practice screen in a Mix mode: the title area shows "Mix · 2 of 3 · <lesson title>" / "Mix · 2 ze 3 · <název>".
2. Each lesson plays one normal scored run (the ticket 59 run length) at its own **goal tempo**, with its own pattern, pad layout and sound kit. No automatic tempo change in Mix.
3. Between lessons: playback stops, the next lesson loads, and a one-bar count-in at the next lesson's tempo starts it automatically. Seamless switching is not required.
4. A **From memory** toggle on the Mix card (default off) applies to all three; ticket 99 fading applies per lesson (each lesson's first appearance is its pass 1).
5. Each run is recorded to its lesson exactly like a normal full run: stars, Learning credit, reviews (a due lesson's From memory run counts as its review). Challenge mode streaks are per lesson as today.
6. STOP ends the Mix; the result card shows one line per lesson (score, bar verdicts summary) and "Again" / "Znovu".
7. Section loop, Listen and the tempo control are unavailable during Mix.
