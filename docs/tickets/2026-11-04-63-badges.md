# 63 — Badges (from the original tool) and the home pad "Odznaky"

Status: ready. Source: Jakub, 2026-11-04. Run after ticket 62 (it frees the home cell).

## Goal

Long-term goals beyond stars of one lesson: badges for passed, mastered and memorised lessons and for completed groups, as in the original tool. A badges screen, a quiet "new badge" note after a run, and the home pad **Odznaky / Badges**.

## Source (legacy, read-only, data only)

This ticket explicitly allows reading the legacy file `~/AI COWORK/Smack-a-Pad/Smack-a-Pad/2026-10-28-Smack-a-Pad-ipad/app/v21/src/ui/rewards.js` (`REWARDS_BADGES`, `REWARDS_BADGE_GROUPS`, `REWARDS_BADGE_TIERS`, the Czech strings at the top) and `…/app/v21/i18n/cs.tsv` for the Czech names. **Copy the data (ids, names, conditions, goals, tiers, groups) into a new bundled JSON file; do not copy or port the JavaScript.** Write the Swift logic from this ticket.

Legacy badge shape: `[id, name, condition, {metric, goal, tier 1–3 (Bronze/Silver/Gold), group}]`; `goal` is a number, `'catalogue'` (all lessons) or `'group'` (all lessons of that group). A badge is earned once and keeps its date.

## Which badges

Keep only metrics this app can compute from saved progress (`LessonProgress`: `passed`, `mastery`, `memory`) and the catalogue (`LibraryCatalog`: path stages, `lesson.level`, genre groups, technique groups):

| Group (legacy) | Metric | Counts |
|---|---|---|
| Passed lessons | `passed` | lessons with star 1 |
| Goal tempo | `mastered` | lessons with star 2 |
| Memory practice | `memory` | lessons with star 3 |
| Completed stages | `courses` | path stages whose lessons all have star 2 |
| Levels | `level-N` | all lessons of level N passed |
| Genres | `genre-*` | all lessons of a genre group passed |
| Techniques | `tech-*` | all lessons of a technique group passed |

- **Drop** badges whose metric does not exist here: weekly goals, day series, long-term review, check game, "eight and sixteen". List the dropped ids in the report.
- **Drop** badges with a numeric goal larger than this app's catalogue (unreachable); keep `'catalogue'` ones.
- Genre / technique / level badges are generated **from this app's catalogue groups**, one per group, named like the legacy pattern ("Rock and punk done" / "Rock a punk hotovo"). If a legacy group has no counterpart here, drop it; if this app has a group the legacy tool did not, add one in the same pattern.
- Count a lesson once regardless of pad mode (8/16), as stars are counted in the library.

## Logic and storage

- A `BadgeStore` (persisted like the existing stores, e.g. JSON in `UserDefaults`): `[badgeId: earnedAt]`.
- `BadgeEvaluator` (pure function: progress + catalogue + definitions → stats and newly earned ids). Evaluate after every saved pass and once at app start.
- **At app start**, badges already deserved (existing players, legacy import) are awarded **silently**, with no announcement.
- Badges never get revoked.

## Badges screen

- Opened from the home pad (sheet with `NavigationStack` and Done).
- Grouped as in the table (group titles via `SectionHeader`), each badge one row in the library-row style: name, condition (one line, secondary), on the right either the earned date or progress `done / goal` with a thin progress line.
- Tier shown as 1–3 small filled marks (not bronze/silver/gold colours: the palette is orange, black, white). Earned badge = orange mark(s) and ink text; not earned = hairline marks and secondary text.
- Header line: "Odznaky 12 / 40". No icons per badge, no default SF Symbols, no card grid.

## Announcement

- After a run that earns a badge, the result area shows one quiet line "Nový odznak: {name}" (several: "Získány {count} nové odznaky"), next to the existing star result, without stopping the lesson and without covering the pattern. Nothing appears during a running pass.
- VoiceOver announces it once.
