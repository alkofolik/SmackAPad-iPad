## Decisions by Jakub

1. **Proposal A, "the logo is the menu", but as a 3×3 grid of nine pads** (not the four large pads of the HTML). The big logo stays as the hero; the nine pads are the menu.
2. **Nine items**, listed below.
3. **Colours follow the rest of the app** (`Theme` tokens, light and dark). The cream-in-both-appearances recommendation of ticket 60 is **not** adopted for the home screen. Only the animation itself still starts on cream (the static launch screen of ticket 46 stays unchanged).
4. **Navigation**: Home → Library → Practice. Back from the library goes to Home; back from a lesson goes to the Library (as today).

Its SVG has `viewBox="0 0 490.455 73.8"` while its path coordinates live in the original logo's coordinate space (starting at about x 110, y 60), so only a corner of it is visible. **Do not copy any SVG from the HTML.** Use the wordmark that already exists in the app (`LaunchWordmark.imageset`, preserves vector data) and the logo geometry from `LaunchAnimationView.swift`. The finished logo with wordmark must be **complete, uncropped and centred in its area** in portrait and landscape on 11" and 13", in light and dark (see acceptance criteria).

## The nine pads

Reading order, left to right, top to bottom. All pads are the same size. Only text, no icons (design-brief reject list: no untouched default SF Symbols).

| # | Label (cs / en) | Face shows (second line) | Tap |
|---|---|---|---|
| 1 | **Pokračovat / Continue** (first run, `lastLessonID == 0`: **Začít / Start**) | next lesson name and its stars (first run: first Intro lesson) | Opens the Library with the next lesson's practice screen already presented. Next lesson = same logic as the Library's `next` (`progression.nextLesson(after: lessonStore.lesson(for: settings.lastLessonID), source: …)`). |
| 2 | **Knihovna / Library** | – | Opens the Library. |
| 3 | **Nastavení / Settings** | – | Opens the existing settings sheet. |
| 4 | **Úvodní cvičení / Intro** | – | Opens the Library on the Intro page (`showingIntro`). |
| 5 | **Ovladač / Controller** | controller name when `midi.sources` is not empty, else "Připoj ovladač / Connect a controller" | Opens Settings (scrolled to the hardware section if that is easy; otherwise just Settings). |
| 6 | **Kalibrace / Calibration** | saved latency value if the settings store has one, else "Nezměřeno / Not measured" | Presents `CalibrationView` in its own sheet with a Done button. If that is not trivial, open Settings instead and say so in the report. |
| 7 | **Pokrok / Progress** | stars earned of all, e.g. `42 / 216` (from `ProgressStore` and the catalogue) | Opens the Library. No new progress page in this ticket. |
| 8 | **Plná verze / Full version** | "Odemknout / Unlock" while content is locked, "Odemčeno / Unlocked" when everything is owned | Opens the existing purchase sheet in both cases (it also holds restore). |
| 9 | **O aplikaci / About** | version number | Small popover: app name, version, and the line "Písmo IBM Plex Sans, SIL OFL 1.1 / Font IBM Plex Sans, SIL OFL 1.1". |

Pad 1 is **orange** (`Theme.orange`, black text) and its first-line text is larger; all other pads use `Theme.surface` with `Theme.ink` text and a `Theme.hairline` outline. The nine positions never change (muscle memory), only the second lines do.

- The logo is the largest element on screen; the pads are squares sized from the available area (gap `Theme.Space.regular`, outer margin `Theme.Space.wide`). Everything is computed from the container size (`GeometryReader`), so it also works in Split View / Slide Over; no hard-coded device sizes.
- Labels in IBM Plex via existing `Theme` fonts (`Theme.action` for the label, `Theme.meta` for the second line); long labels may use two lines and `minimumScaleFactor` down to 0.8, never truncate with "…". Pad corner radius `Theme.Radius.pad`.
- Pressed state: darker fill and a 0.97 scale for 0.1 s (a tactile pad); no sound, no glow.

## Animation → home

Rework `LaunchAnimationView` so its last frame **is** the home screen (today it fades out). Keep the existing logo build (pads pop, orange smack at 12°, wordmark rise); the timeline becomes:

| Time | What happens |
|---|---|
| 0.00–1.50 s | As today on cream: three black pads, the orange smack, the wordmark. |
| 1.50–2.10 s | The logo block settles to its home position and size (left in landscape, top in portrait). At the same time the background cross-fades from cream to `Theme.background`, and in dark appearance the logo cross-fades to its on-dark colours (`docs/design/2026-11-03-logo-source/smack-a-pad-logo-horizontal-on-dark.svg`; give the asset catalog image set a dark variant). |
| 2.10–2.70 s | The nine pads appear one after another, 0.06 s apart, in reading order, with a small scale/opacity pop. Each pad is tappable as soon as it is visible. |
| 2.70–3.20 s | Done. The animation never fades the logo out. |

- Tap anywhere during the animation jumps to the finished home screen.
- Cold start only. Returning from background does not replay it. Returning Home from the Library or a lesson shows the finished home screen with at most a 0.25 s cross-fade (no logo animation).
- **Reduce Motion**: no movement; the finished home screen fades in over 0.25 s.
- The animation must not delay `store.start()` / `midi.start()` / data loading (as in ticket 46).
- Remove the `preferredColorScheme(.light)` workaround in `SmackAPadApp.swift` only if it is no longer needed; the animation's cream stage must still look right in dark appearance.
- Native SwiftUI only; no new packages.

## Navigation

- `SmackAPadApp` root shows the Home screen and the Library as two routes with a simple transition (0.25 s cross-fade; `Theme.Motion` policy for Reduce Motion). Settings, calibration, purchases and About are sheets/popovers from Home as in the table.
- `LibraryScreen` gets a small launch parameter (nothing / Intro page / present this lesson) set by pads 1 and 4, and a **"Domů / Home" button** that returns to Home. It must be reachable in one tap, at least 48 pt high, and must not collide with the sidebar toggle or the existing Settings button; choose the placement (sidebar toolbar leading is the recommendation) and mention it in the report.
- A lesson opened through Continue returns to the Library when closed (the existing behaviour of the practice screen). The Library's own "Next" banner stays as it is.
- No change to the practice screen, scoring, audio, MIDI or the existing settings content.
